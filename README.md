# Temario TCEE

Todos los temas de la oposición, uno por carpeta:

```
Ejercicio-3/Parte-A/3.A.1 … 3.A.45
Ejercicio-3/Parte-B/3.B.1 … 3.B.45
Ejercicio-4/Parte-B/4.B.3 … 4.B.26
```

Cada carpeta contiene el `.tex` del tema y sus figuras. Los PDF no se guardan aquí (van a iCloud).
Las herramientas, la guía de uso y la explicación del historial de cambios están en el repositorio
[main](https://github.com/OposicionTCEE/main) (ver `HISTORIAL.md`).

Este repositorio reúne los antiguos repositorios `Tema-X.Y.Z`, con todo su historial.
